# ForeverAdventurer — Worldwide Travel Publication & Free Printable Library

> An independent worldwide travel publication combining thoughtful travel journalism, comprehensive country and destination directories, interactive planning tools, and a large library of genuinely free printable resources.

---

## 🧭 Project Overview

**ForeverAdventurer** is built using modern web standards with an editorial design inspired by leading travel publications.

### Core Pillars
1. **Curated Worldwide Directory**: Structured exploration across 6 continents (Europe, Asia, Africa, North America, South America, Oceania).
2. **Travel Diaries**: Mindful, observant personal essays focusing on slow journeys, cultural immersion, and solitary walks.
3. **Practical Travel Guides**: In-depth multi-day itineraries with logistics, seasonal guidance, and estimated budgets.
4. **Free Downloads Library**: 27+ print-ready PDF planners, journals, and checklists (A4 & US Letter) available without registration.
5. **Interactive Trip-Planning Suite**: In-browser packing checklists, budget calculators, and itinerary boards.

---

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router, React 18 / TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com) with bespoke editorial typography (`Playfair Display` serif & `DM Sans`)
- **Icons**: [Lucide React](https://lucide.dev)
- **Deployment**: Ready for [Vercel](https://vercel.com) & GitHub

---

## 🚀 Running Locally

### 1. Requirements
- Node.js (v18.17+ or v20/v22 LTS)
- Git

### 2. Start the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
